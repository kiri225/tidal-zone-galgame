# 潮间带 / Intertidal Zone

成人向 galgame（Vue 3 + TypeScript + Pinia）。

## 运行

```bash
npm install
npm run dev
```

## 资源约定

| 类型 | 路径 | 要求 |
|------|------|------|
| 背景 | `public/images/bg/` | 完整场景图 |
| 立绘 | `public/images/char/` | **透明底 PNG（RGBA）**，不要带实景背景 |
| CG | `public/images/cg/` | 全屏插画 |

## 好感 → CG

| CG | 亲密度 |
|----|--------|
| 潮声重逢 | ≥ 3 |
| 关店夜话 | ≥ 6 |
| 雨困一夜 | ≥ 10 |
| 潮间带 | ≥ 14（或 True End） |

## 结局条件（晚棠线）

| 结局 | 条件 |
|------|------|
| True | 亲密度 ≥ 8，且选择留下 + 坦白 |
| Good | 亲密度 ≥ 5，且留下或坦白其一 |
| Bittersweet | 其他 |

操作：点击对话框外区域 / 空格 / 回车推进；出现选项时点击选项。标题页可进「CG 鉴赏」。
